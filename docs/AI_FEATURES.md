# EmotePay AI Features

## AI Reaction Director

Input:
- donation message
- emote
- amount

Output:
- safe_to_display
- sentiment
- intensity
- recommended_animation

AI never controls the payment.

## Creator Stream Copilot

Input:
- donation history
- timestamps
- emotes
- messages

Output:
- stream summary
- highlights
- top reactions
- suggested clip timestamps
- supporter thank-you draft

## Privacy

Messages remain offchain.
No personal information is written to Solana.
